# SBRM 2027 · Concepción

Sitio oficial de la Student Branches Regional Meeting 2027 en Concepción, Chile, presentada por IEEE Sección Chile Sur y la Universidad de Concepción.

## Desarrollo local

La página es un sitio estático dentro de `dist/`.

```powershell
python -m http.server 4173 --directory dist
```

La fecha del encuentro es tentativa: 28 de octubre al 1 de noviembre de 2027.
